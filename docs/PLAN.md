# Kotoba – Plan

## Goal

A personal, local-first desktop app for daily Japanese practice. It takes tests,
grades them, and uses spaced repetition to bring weak words and skills back at
the right time.

Built partly as a learning project: understanding how the app works matters as
much as finishing it.

## Key decisions

- **Stack:** Electron + TypeScript + React + Vite, SQLite (built-in `node:sqlite`, no native build), Zod, Vitest.
- **Local-first:** everything runs and is stored on this machine. No backend, no accounts.
- **Tests are JSON files.** Each question uses one of a fixed set of question
  templates the app knows (multiple_choice, reading, meaning, cloze, conjugation,
  reorder, translation). Templates are code; tests are data.
- **Questions name their targets** (word or grammar point + skill). Progress and
  scheduling attach to targets, not to individual questions, so tests can be
  thrown away and regenerated freely.
- **Grading:**
  - Local, against defined answers: multiple_choice, reading, reorder, conjugation, exact cloze.
  - Local first, AI if no match: meaning, flexible cloze.
  - AI or self-check: translation and free writing.
  - The app, not the AI, decides the review rating.
- **Reading input:** romaji converted to kana as you type (wanakana).
  Katakana is accepted as hiragana; small kana, long vowels and dakuten must be exact.
- **Scheduling:** FSRS (ts-fsrs) per target + skill.
- **Inbox folder:** any valid test file dropped into `inbox/` is checked and imported,
  whether written by hand, pasted from a chat, or generated by `claude -p`.
- **Generation:** the app exports a "what to practice" brief; Claude turns it into a test.
  Starts manual, then automated with `claude -p` on my own machine.
- **Security basics:** context isolation, sandboxed renderer, a small preload API.
  Secrets never committed.

## Not now

- Languages other than Japanese
- Speaking, listening, handwriting
- Sync, accounts, multiple users
- Distribution, auto-updates, code signing
- Calling the Claude API from inside the app (until milestone 7)
